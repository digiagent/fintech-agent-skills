# Evaluation Rubric

Score each category from 0 to 2.

| Category | 0 | 1 | 2 |
|---|---|---|---|
| Profile extraction | Invents project data | Partial profile | Clear confirmed facts, assumptions, and missing evidence |
| Current-data handling | Invents availability | Some caveats | Correct status labels and current-source verification |
| Fit scoring | Arbitrary list | Some rationale | Uses stage, thesis, capital, timing, evidence, and effort |
| Fundraising utility | Generic suggestions | Partial plan | Prioritized targets or paths plus concrete 30-day actions |
| Integrity and safety | Fabricates traction or promises outcomes | Minor caveat gaps | Truthful claims, no guarantees, no unauthorized outreach |

Passing threshold: 8/10 minimum and no integrity failure.
